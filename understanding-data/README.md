# Understanding Data — Complete Interactive Learning Course

Self-contained, Rise-inspired HTML/CSS/JavaScript course based on the supplied *Learning Design Storyboard — NCFE Level 3 Certificate in Digital Support, Module 1*. This is independently created learning content, not an official NCFE assessment or endorsed qualification product.

## Run locally
Extract the ZIP. Open `index.html` with Microsoft Edge or Chrome. Keep `index.html`, `style.css`, `script.js` and `enhancements.js` together. No installation, login, internet or external libraries required.

## Publish on GitHub Pages
Upload the four files to a folder in your GitHub Pages repository (e.g. `understanding-data/`). Enable Pages if not already enabled. Visit `https://YOUR-USERNAME.github.io/understanding-data/` (adjust for your repository configuration).

## Features
Eight detailed lessons, native disclosure cards, data type and system matching, search-algorithm step-through, storage scenario advisor, reflection notes, 15-question formative check, practical assessment brief, learner workbook, tutor guide with suggested rubric and answer guidance, and text-only transcript. Download resources via buttons in the course. Progress and notes are saved in this browser's local storage; they do not sync across devices.

## Important teaching notes
The 15-question check is **formative practice**, with a suggested 80% target (12/15), not an NCFE grading rule. The original storyboard calls for a welcome video and short animated media; this offline release provides a text-based welcome and an interactive algorithm animation rather than recorded video. All required explanations are available in text. Suggested tutor materials are downloadable text files, not a separately designed PowerPoint or Rise file. Formal assessment requires the current NCFE specification and centre procedures.
