ESSENTIAL DIGITAL SKILLS ENTRY LEVEL 3 — MODULE 1

HOW TO USE
1. Unzip the package.
2. Open index.html in a modern browser, or upload the folder contents to a GitHub Pages repository.
3. For GitHub Pages: create a repository or folder, upload index.html, style.css, script.js, lessons.json and practice/ without changing their relative paths. Enable Pages in repository Settings if needed.
4. Learners use the lesson menu and Continue / Previous buttons. Progress and quiz answers are saved in their own browser's local storage; no learner account or server is required.

CONTENTS
index.html — main course
style.css — accessible responsive design
script.js — lessons, interactive quizzes, checklist, navigation and progress
lessons.json — outline metadata
practice/Text_File_Example.txt — original downloadable exercise
practice/Practice_Notes.txt — original practical activity sheet
TUTOR_GUIDE.txt — delivery, mapping and testing notes

NOTES
Original practice content is aligned with Gateway Qualifications Entry 3 Unit 1 resources and specification. It is not an official assessment or a replica of restricted papers. The online knowledge quiz cannot verify real-device practical tasks. The tutor should observe these separately. For shared classroom computers, browser progress is device/browser-specific and may be cleared between sessions.
