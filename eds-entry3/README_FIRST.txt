EDS ENTRY LEVEL 3 — COMPLETE INTERACTIVE COURSE + ASSESSMENTS

1. Extract the ZIP. Keep all folders and filenames unchanged.
2. Upload index.html, hub.css, assessments.html, assessment.css, assessment.js, and module1–module5 folders to a GitHub Pages folder (for example eds-entry3).
3. Open /eds-entry3/ and select Assessments & learner progress.
4. Learners should download their CSV reports after completing quizzes.
5. Keep EDS_Entry3_Tutor_Progress_Tracker.xlsx PRIVATE on your own computer or centre storage. Do not publish it on GitHub.
6. Read ASSESSMENT_AND_TRACKING_GUIDE.md before teaching.

This course supports Entry Level 3 learning. All assessments are original/internal practice resources and are NOT official Gateway Qualifications papers. The website does not collect or transmit learner information. Progress is stored in the current browser only.
