# EDS Entry Level 3 — Assessment and tracking guide

## Contents
- Five **10-question module knowledge checks** (50 items)
- Mid-term 1 (15 questions, suggested week 5)
- Mid-term 2 (20 questions, suggested week 10)
- Two original practical mock scenarios, each with 15-question integrated knowledge check (suggested weeks 13 and 15)
- Final **internal practice** assessment: 25 questions and an integrated practical scenario (suggested week 16)
- Downloadable per-learner CSV progress report; Excel class tracker; tutor practical rubric

The mid-term, mock and final knowledge checks intentionally reuse a selection of previously taught question-bank items for revision and consolidation. The practical mock scenarios are original and distinct. These are **practice resources, not secure or official Gateway assessment papers**. Because answer keys are delivered in client-side JavaScript, they cannot be used as high-stakes invigilated assessments.

## Using the learner report
1. Give each learner a **non-identifying code** (EDS-001, etc.). Avoid names and dates of birth on the website.
2. Learners complete knowledge checks on the same browser/device and tick practical tasks when done.
3. Learners choose **Download progress CSV**. The file includes all ten assessment slots, latest score, best percentage, attempt count, date and self-reported practical tick.
4. Collect CSVs using an approved secure centre method. **Do not put learner reports or the class tracker on public GitHub Pages.**
5. Open `EDS_Entry3_Tutor_Progress_Tracker.xlsx`. Paste each learner CSV's data rows (excluding the header) into `RESULTS IMPORT` and enter matching learner codes in `CLASS TRACKER`.
6. Review the automatically calculated scores and use `PRACTICAL RUBRIC` for separate tutor observation. The class tracker is a working record, not an official qualification result.

## Practical observation rubric
For each area, record **Achieved / More practice / Not observed** with evidence and date:
- Using devices: identifies equipment, adjusts an accessibility setting, saves/locates files and demonstrates simple troubleshooting.
- Creating/editing: creates, edits, formats and saves an appropriate document and digital media item.
- Communicating: uses an email with suitable recipient, subject and attachment; joins a supervised video call and uses microphone/camera controls.
- Transacting: accurately completes a simulated form and reviews a mock purchase safely. Never collect payment details.
- Online safety: recognises phishing and privacy risks, explains secure access and reporting, and demonstrates digital wellbeing choices.

### Mock 1 — Community centre open day
Scenario: You volunteer to help organise a free community centre open day.
1. Create an `Open_Day` folder.
2. Create a one-page notice with heading, date, time, location, three activities and a suitable image. Save as `Open_Day_Notice.docx`.
3. Send a supervised practice email with an appropriate subject and attach the notice.
4. Complete a **fictional** booking form and explain two checks before an online transaction.
5. Identify two signs of a suspicious email requesting event login details.

### Mock 2 — Library digital workshop
Scenario: A library is running a beginner digital skills workshop.
1. Create `Library_Workshop` folder and save a downloaded text file inside.
2. Create a simple workshop flyer with a clear heading, list and image.
3. Draft a practice email sharing the flyer and a relevant webpage link.
4. Complete a fictional workshop registration; check required fields.
5. Identify a phishing warning and explain what to report and to whom.

### Final internal practical — Community support event
Create and organise an event folder, prepare a notice, share it by practice email, complete a simulated registration and explain an accessibility choice, a security risk and a safe response. The tutor checks evidence from all five skill areas.

## Data and technical limitations
- Browser progress is local to the browser profile and may disappear if the browser data is cleared or a different device is used.
- No account, cloud sync or tutor-facing live dashboard is included.
- The CSV includes assessment results and self-reported practical ticks; **it does not automatically export lesson-page completion** from the older module navigation.
- Assessment records are stored locally; do not use shared public computers without a plan to export and clear learner data after each session.
- The workbook is designed for up to 30 learner codes and 1,000 pasted result rows. Replace old rows rather than appending duplicate exports for the same learner; otherwise scores may be summed.
- A suggested 80% practice benchmark is for formative teaching only and is **not** an official Gateway pass mark.
